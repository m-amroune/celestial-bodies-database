#  Project : Celestial Bodies Database

##  About the Project

**Objective** : Build a relational PostgreSQL database that models celestial bodies such as galaxies, stars, planets, and moons. The project is part of FreeCodeCamp’s Relational Database Certification and is completed using a Linux environment with PostgreSQL and Bash.

The database follows a normalized schema and includes relationships between entities. All tasks are guided and validated through the CodeRoad interface.

##  Project Tasks

- Create a PostgreSQL database named `universe`
- Define tables for `galaxy`, `star`, `planet`, and `moon`
- Use appropriate data types and constraints (`NOT NULL`, `UNIQUE`, `FOREIGN KEY`, etc.)
- Insert at least 6 rows into each table
- Establish relationships:
  - Stars belong to galaxies
  - Planets orbit stars
  - Moons orbit planets
- Write SQL queries to demonstrate joins, filtering, and aggregation
- Pass all automated tests provided by CodeRoad
